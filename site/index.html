# Sugestão Porque gostei de Na fila
Como os dados foram reunidos
Fontes
API oficial do MyAnimeList (animes, mangás e notas), AniList (elenco, equipe e a obra de origem de cada anime), Kitsu (guia de episódios) e o anime-offline-database (ligação entre os sites). Primeira carga entre 1º e 5 de novembro de 2026; dados desta página atualizados em —.
Pipeline
Python para a coleta, respeitando o limite de requisições de cada API; DuckDB como data warehouse; dbt para modelar e testar os dados em camadas. Código aberto em github.com/GabrielKSG7/MAL-ANALYTICS.
Nota mediana
O valor do meio quando os títulos são ordenados pela nota. Diferente da média, não é puxada por poucos sucessos ou fracassos.
Adaptações
Comparação entre a nota do anime e a da obra que ele adapta, só para animes com uma única obra de origem. "Praticamente empatado" significa diferença de até 0,25 ponto.
Recomendador
Modelo de conteúdo: cada anime vira um vetor com gêneros, temas, estúdio, tipo de obra original e década, e as sugestões são os títulos mais parecidos com os que recebi nota alta. Os títulos que já assisti ficam de fora. Com dados de outros usuários, o mesmo código combina esse modelo com filtragem colaborativa.
O que ficou de fora
Títulos sem nota, episódios sem data e as edições de antes de 1995 no gráfico de notas, que têm poucos títulos por ano.
